# Newsletter sample email

Static design document for the Desert Sentinel alert email.

- **File:** [`sample-email.html`](./sample-email.html)
- **Not wired** into `/newsletter` or any app route.
- Open the HTML in a browser to review layout and copy.

## What it simulates

All product triggers from the signup criteria, plus the optional monthly digest:

| Trigger | Sample territory | Fictional signal |
| --- | --- | --- |
| Trend shift | Petrolina (PE) | +3.8 → +9.4 p.p. (≥ 5 p.p.) |
| Risk category | Tauá (CE) | Moderate → High |
| Impact type | Ouricuri (PE) | Migration / emergency added |
| New territory at risk | Jaguaribe (CE) | Enters High filter |
| Monthly digest | Selection roll-up | Cost, risk index, carbon @ US$ 15/tCO₂e |

Figures are invented for credibility in the Caatinga / sertão context. They are not live satellite products.
